Complete Predefined Rule Catalog

All business decisions in RuleBus are governed by these exact Python functions.

Seat Module

Seat Availability & Capacity Rule

IF requested_seats <= available_seats
THEN allow_booking = True
ELSE
THEN reject_booking = "Not enough seats available."
Example: Requested 2 seats, Available 30 → Booking Allowed.
Fare Module

Passenger Age Discount Rules

IF age < 5
THEN ticket_fare = FREE (100% discount)

IF age >= 5 AND age <= 12
THEN apply 50% Child Discount

IF age >= 60
THEN apply 10% Senior Citizen Discount

IF age > 12 AND age < 60
THEN charge Normal Fare
Example: Base Fare ₹500, Age 10 → Child Discount 50% → Fare = ₹250.
Fare Module

Group Booking Discount Rule

IF total_passengers >= 4
THEN apply 5% Group Discount on Subtotal
ELSE
THEN group_discount = 0%
Example: 4 passengers with subtotal ₹1,800 → 5% Off (-₹90) → Final = ₹1,710.
Fare Module

Weekend Travel Surcharge Rule

IF travel_day IN ("Saturday", "Sunday")
THEN add 10% Weekend Surcharge
ELSE
THEN surcharge = 0%
Example: Base ₹1,000 on Saturday → 10% Surcharge (+₹100) → Total = ₹1,100.
Status Module

Booking Status Determination Rule

IF payment_successful == True AND seats_available == True
THEN booking_status = "CONFIRMED"

IF payment_successful == False
THEN booking_status = "PAYMENT FAILED"

IF seats_available == False
THEN booking_status = "REJECTED"
Example: Seats available & UPI payment successful → Status: CONFIRMED.
Refund Module

Time-Tiered Cancellation Refund Rules

IF hours_before_departure > 24
THEN refund = 80% (20% fee)

IF hours_before_departure >= 12 AND <= 24
THEN refund = 50% (50% fee)

IF hours_before_departure < 12
THEN refund = 0% (100% fee)
Example: Ticket ₹1,000 cancelled 30 hrs before departure → Refund = ₹800.
